# WBS

- 상태: 초안
- 원칙: **가장 불확실하고, 안 되면 프로젝트가 성립하지 않는 것(웹 터미널)부터** 검증한다.
- 예상 기간은 **퇴근 후·주말 기준 주 10시간 안팎**을 가정한 대략치. 실적을 기록하면서 보정한다.
- 진행 추적은 GitHub Issues + GitHub Projects로 한다. WBS 항목 하나 = Issue 하나, Phase는 라벨로 구분.

## 마일스톤

| 마일스톤 | 완료 조건 | 포함 Phase |
|---|---|---|
| **M0** 개발 환경 | 로컬에서 frontend ↔ backend ↔ DB 연결 확인 | 0 |
| **M1** 기술 검증 | 브라우저에서 컨테이너 셸 조작 + 정답 판정 1건 성공, 자원 측정 완료 | 0.5 |
| **M2** 핵심 루프 | 게스트로 문제 선택 → 터미널 → 제출 → 정답 판정까지 동작 | 1 |
| **M3 = MVP** | runner 보강, 몸풀기 테스트, 진행 기록 화면까지 로컬에서 동작 | 2 ~ 3.5 |
