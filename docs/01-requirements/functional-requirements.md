# 기능 요구사항

- 상태: 초안
- 우선순위: **MVP** = Phase 0~3.5에서 구현 / **Later** = 이후 단계
- 대상: **G** = 게스트, **M** = 회원

## 게스트 식별 (GST)

| ID | 요구사항 | 대상 | 우선순위 |
|---|---|---|---|
| FR-GST-001 | 첫 방문 시 게스트 ID를 발급하고 쿠키로 유지한다 | G | MVP |
| FR-GST-002 | 게스트의 풀이 기록, 테스트 결과를 게스트 ID에 연결해 저장한다 | G | MVP |
| FR-GST-003 | 게스트에게 "브라우저 데이터를 지우면 기록이 사라진다"는 안내를 표시한다 | G | MVP |
| FR-GST-004 | 회원가입 시 해당 브라우저의 게스트 기록을 회원 계정으로 이전한다 | G→M | Later |
